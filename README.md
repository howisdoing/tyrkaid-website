# TYRKAID Product Category Image Import

产品分类后台新增“分类图片”。

支持：
- 上传分类图片
- 从媒体库选择已有产品图片
- 从媒体库替换
- 移除分类图片
- 产品分类列表显示缩略图

首页“产品系列”图片优先级：
1. 分类后台指定的分类图片
2. 未指定时自动使用该分类下第一张产品图
3. 都没有时显示占位图

## D1
新增 `categories.image_url` 字段。

部署后不需要你提前手动迁移：
- 第一次保存产品分类时，后台会自动检查并创建 `image_url` 字段。
- `d1/schema.sql` 已包含该字段，供新部署使用。
- 也附带 `d1/category-image-migration.sql`，需要时可手动执行。

媒体库中若移动或重命名正在作为分类图片使用的图片，系统会同步更新 D1 引用。
