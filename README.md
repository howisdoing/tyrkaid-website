# TYRKAID Horizontal Customizer + Homepage Section Builder

## 网站装修布局
网站装修不再使用左侧竖排折叠菜单。

顶部横向标签：
- 公司与品牌
- 顶部 Header
- 首页 Banner
- 首页功能区
- 关于我们
- 联系我们
- 页脚 Footer

实时预览移动到设置区下面。

## 首页功能区 Builder
首页功能区现在保存在 `site_settings.data_json.home_sections`，不新增 D1 表。

支持：
- 上移
- 下移
- 新建
- 复制
- 删除
- 显示 / 隐藏
- 修改后台模块名称
- 修改前台眉题、标题、说明
- 设置区块色调

内置模块：
- 首页 Banner
- 产品系列
- 精选设备
- 关于我们
- 公司动态
- 自定义内容

自定义内容模块另外支持：
- 图片
- 按钮文字
- 按钮链接

前台首页会按照后台设置的模块顺序真实渲染。

## 颜色
后台首页模块使用不同浅色和左侧色条区分。
颜色主要用于后台识别；部分色调也会轻量反映到前台模块背景。

## D1
无需数据库迁移。
所有新增配置继续保存在现有 `site_settings.data_json`。
