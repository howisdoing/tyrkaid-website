# TYRKAID Shopify / WordPress Style Customizer

本版把“网站装修”改成更接近 Shopify / WordPress 自定义器的工作方式。

## 左侧分组
- 公司与品牌
- 顶部 Header
- 首页 Banner
- 首页内容
- 关于我们
- 联系我们
- 页脚 Footer

每组可折叠，避免原来一整页表单过长。

## 右侧实时预览
- 桌面预览
- 手机预览
- Logo / Header / 导航 / Banner / About / Contact 实时联动

## 保存
- 顶部固定保存栏
- 保留原有 D1 自动保存
- 同时保留手动“保存”按钮

## 数据结构
不新增 D1 表或字段。
继续使用现有 site_settings.data_json，因此无需数据库迁移。

## 其他功能
产品、媒体库、多级文件夹、新闻、导航等功能不变。
