# TYRKAID Product Media Library Editor

本版把产品图片管理改成电商式结构。

## 产品图片分组

### 主图 / 商品图
- 第一张自动作为产品封面
- 用于：首页推荐、产品中心缩略图、分类页、产品详情顶部轮播
- 支持上传
- 支持从媒体库导入
- 支持上移 / 下移 / 删除

### 详情图
- 只用于产品详情页下方“产品详情图”
- 适合设备细节、尺寸、结构、应用场景等
- 支持上传
- 支持从媒体库导入
- 支持上移 / 下移 / 删除

## 数据兼容
不新增 D1 字段。
继续使用 products.images_json：

新格式：
{
  "main": ["/uploads/products/a.webp"],
  "detail": ["/uploads/products/b.webp"]
}

旧格式数组会自动按主图读取，因此旧产品不会丢图。

不需要执行数据库迁移。
