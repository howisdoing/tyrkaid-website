# TYRKAID Website - Clean Release

这是当前精简发布版。

保留功能：
- Cloudflare Workers + Static Assets
- D1 产品 / 分类 / 新闻 / 网站设置
- 后台首页控制台
- 产品编辑“推荐到首页”
- 图片库与 GitHub 图片上传
- 产品多图图库
- 网站装修
- 导航管理
- 吸顶页头
- SEO robots / sitemap
- llms / ARD 兼容
- Logo 自适应显示

部署：
1. 整包覆盖 GitHub 仓库。
2. Commit。
3. 等待 Cloudflare 自动部署。
4. 原有 D1、Secrets、GitHub Token 配置不用重新设置。
