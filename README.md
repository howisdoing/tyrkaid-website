# TYRKAID Stable Recovery Package

本包用于恢复后台数据正常显示。

已修复：
- 后台 Dashboard 登录后会自动调用 `/api/admin/items`
- 正常读取 D1 的分类、产品、新闻、网站设置、导航
- 接口返回异常时明确显示“后台数据读取失败”
- 后台顶部增加“刷新数据”按钮

重要：
- `.md` 文件不参与网站运行，误删说明文件不会删除 D1 数据。
- `/api/catalog` 已证明 D1 数据仍在。
- 本包保留当前已有功能：产品主图/详情图、媒体库多级文件夹、分类图片、网站装修、Banner 编辑、微信二维码等。
- 不要重新执行 `d1/schema.sql` 去覆盖数据库。
- 直接整包覆盖 GitHub 仓库并提交即可。
